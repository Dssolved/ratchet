# Ratchet

Оффлайн-трекер тренировок по калистенике. Название — от храпового механизма: прогресс
фиксируется по ступеням и не откатывается.

Приложение для одного человека, без аккаунтов и без сервера. Собирается в APK для Android,
тот же код работает как PWA.

## Зачем

Год уличных тренировок, а прогресс невидимый: непонятно, растёшь ты или топчешься.
Причины оказались две, и обе чинятся структурой, а не силой воли:

1. **Варианты упражнений смешивались.** Сегодня отжимания с ногами на возвышении, через
   неделю на упорах с пола — цифры несравнимы, и никакой график из них ничего не покажет.
2. **Достигнут потолок повторений.** 3×15 — это уже выносливость, а не сила. Дальше расти
   в повторениях можно бесконечно с падающей отдачей.

Ratchet заставляет держать одну ступень сложности, пока диапазон не закрыт, а потом сам
предлагает усложниться. Повторения при этом падают — и это правильно.

## Как устроено

**Хранятся только факты и решения.** Факты — записанные подходы, решения — переходы
по ступеням. Рекорды, стрики, готовность к усложнению, счётчики и достижения считаются
из журнала на лету и никогда не хранятся. Поэтому новая метрика, добавленная через полгода,
сразу считается по всей накопленной истории.

Данные живут в IndexedDB на устройстве. Бэкап — экспорт JSON.

## Стек

Vite · React · TypeScript · Tailwind · Zustand · Recharts · Capacitor.
Версии и обоснования — в [CLAUDE.md](CLAUDE.md#стек).

## Запуск

```bash
npm install
npm run dev              # дев-сервер
npm run dev -- --host    # с доступом по локальной сети, чтобы открыть с телефона
npm run check            # typecheck + линтер
```

Сборка APK — см. [docs/android.md](docs/android.md).
