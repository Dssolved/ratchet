# Экраны и взаимодействие

## Условия использования, из которых следует всё остальное

Уличная площадка. Телефон в руке между подходами, иногда мокрые или замёрзшие пальцы,
солнце в экран, перчатки зимой. Всё, что требует прицеливания или клавиатуры, — провалено
по умолчанию.

Отсюда жёсткие правила:

- **Никакого текстового ввода во время тренировки.** Числа вводятся степперами `−`/`+`,
  клавиатура не поднимается никогда.
- **Тач-таргеты от 48×48 dp**, между кнопками подходов — заметные промежутки.
- **Ноль решений внутри тренировки.** Следующее упражнение открывается само, значения
  предзаполнены, навигация не нужна.
- **Отклик на каждое действие** — вибрация (haptics) на отметке подхода и на конце отдыха.

## Навигация: три вкладки

Не пять. Каждая лишняя вкладка — это решение, которое приходится принимать под турником.

```
┌─────────┬──────────┬───────────┐
│ Сегодня │ Прогресс │ Настройки │
└─────────┴──────────┴───────────┘
```

## Вкладка «Сегодня»

### До тренировки

Ровно три блока, сверху вниз:

1. Крупная кнопка **«Начать»** с выбором дня: `День A` / `День B` / `Свободная`.
   Предлагаемый по умолчанию день выводится из того, какой был прошлым.
2. Строка статуса недели: `2 из 3 · стрик 5 недель`.
3. Список движений с последним результатом и цветной точкой готовности — чтобы одним
   взглядом увидеть, где сегодня можно щёлкнуть храповиком.

### Во время тренировки

Это 95% времени использования приложения. Всё остальное второстепенно.

Упражнения дня идут списком, **раскрыто всегда только текущее**. Внутри раскрытого:
название ступени, бейдж диапазона `8–10`, напоминание об оборудовании (`на упорах`),
и строки подходов.

```
  Горизонтальный жим
  Ноги на возвышении ~60 см · 8–12 · на упорах

  1   ✓  10                     ← отмечен, погашен
  2      [ − ]  10  [ + ]   ✓   ← текущий, предзаполнен
  3      [ − ]  10  [ + ]   ✓

  ┌───────────────────────────┐
  │      отдых  1:23     +30с │
  └───────────────────────────┘
```

**Каждая строка предзаполнена результатом прошлой тренировки на этой же ступени.** Это
главная механика экономии тапов: обычное действие — один тап по галочке, изредка `±1`.

Тап по галочке → вибрация → строка гаснет → **автоматически стартует таймер отдыха**
плашкой внизу. Тап по плашке — `+30 сек`, долгий тап — пропустить. По истечении: вибрация
и локальное уведомление, работающее при потушенном экране и свёрнутом приложении.

Когда отмечен последний подход — упражнение сворачивается и **само раскрывается следующее**.
За всю тренировку не нажимается ни одной кнопки навигации.

Для `perSide` движений строка подхода раздваивается на левую и правую сторону.
Для `unit: 'seconds'` вместо счётчика повторений — секундомер с кнопкой «стоп».
Для `kind: 'binary'` вместо чисел — две кнопки: `получилось` / `пробовал`.

### Момент храповика

Если все рабочие подходы закрыли `repMax`, после завершения упражнения выезжает карточка:

```
  ⚙ Ступень взята
  Дальше: Отжимания с весом, +2.5 кг · 8–12

  [ Перейти ]        [ Ещё поработаю ]
```

Автоматически не переключается ничего — решает человек. Но это **главное событие продукта**,
поэтому оно с анимацией щелчка и вибрацией, а не серой строчкой. Пишется в `StepChange`.

### Итог тренировки

Подходы, повторения, длительность, новые рекорды, взятые ступени, прогресс недели `3 из 3`.
Позже сюда встанет подсветка задействованных мышц.

## Вкладка «Прогресс»

Список движений карточками: текущая ступень, позиция на лестнице (`4 / 7` точками),
спарклайн. Тап открывает детали:

**Лестница ступеней** сверху вниз — пройденные, текущая, будущие. Видно, сколько прошёл
и куда идёшь. Это визуальное ядро приложения, а не график.

**График.** По Y — повторения, фон разбит горизонтальными полосами по ступеням, переходы
отмечены вертикальными линиями. Обычный line chart здесь бы наврал: рост до 10, обрыв
до 5, снова рост выглядит как деградация, хотя это триумф. Полосы ступеней делают падение
читаемым как повышение сложности.

**История тренировок** ниже, тап на любую — просмотр и правка (ошибся при вводе — исправил).

**Блок «Всего»** в самом низу: суммарные повторения за всё время, разбивка по движениям,
фильтр `неделя / месяц / год / всё время`. Подписан как статистика ради интереса —
формулировкой, а не мелким шрифтом.

## Вкладка «Настройки»

Справочник движений и ступеней (добавить, переставить, изменить диапазоны), шаблоны дней,
цель тренировок в неделю, длительность отдыха по умолчанию, **экспорт и импорт JSON**.

## Визуальный язык

- Тёмная тема по умолчанию — площадка, вечер, экономия батареи.
- Три состояния готовности: зелёный (`ready`), нейтральный (`in_progress`), серый (`no_data`).
  Цвет — не единственный носитель смысла, рядом всегда текст или иконка.
- Анимации только там, где они несут смысл: щелчок храповика, отметка подхода, конец отдыха.
  Никаких переходов между экранами ради переходов.
