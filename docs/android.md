# Android: окружение, сборка, отладка

Актуально на шаге 2 из [progress.md](progress.md). **До шага 2 ничего из этого ставить
не нужно** — шаги 0 и 1 делаются целиком в браузере.

## Разделение инструментов

| Инструмент | Роль |
|---|---|
| **WebStorm** | весь код, дев-сервер, отладка. Здесь проходит ~95% работы |
| **Android Studio** | нужна не как IDE, а как способ поставить Android SDK и build tools |

Android Studio построена на IntelliJ, интерфейс будет знакомым. После первичной настройки
открывается редко: сборку можно запускать из терминала WebStorm.

## Основной цикл разработки — без Android вообще

```bash
npm run dev -- --host
```

Vite напечатает адрес вида `http://192.168.x.x:5173`. Заходить с телефона по домашнему
Wi-Fi. Тач-интерфейс проверяется на реальном устройстве, изменения прилетают мгновенно,
никакой сборки APK не требуется.

Этого режима достаточно для всего, кроме локальных уведомлений при потушенном экране.

## Разовая настройка (шаг 2)

Точные версии JDK и Android SDK, которых требует Capacitor 8, **уточнить при первой
установке** и записать сюда — в документации Capacitor они меняются от мажора к мажору.

Порядок:

1. Установить Android Studio (тянет за собой JDK и SDK Manager).
2. В SDK Manager поставить Android SDK Platform и Build-Tools нужной версии, а также
   **Android SDK Platform-Tools** (в них `adb`).
3. Переменные окружения: `ANDROID_HOME` на папку SDK, `%ANDROID_HOME%\platform-tools` в `PATH`.
4. На телефоне: включить режим разработчика (7 тапов по «Номер сборки») и отладку по USB.
5. `adb devices` — телефон должен появиться в списке.

## Добавление платформы и сборка

```bash
npm i @capacitor/core@8.5.0 @capacitor/cli@8.5.0 @capacitor/android@8.5.0
npx cap init
npx cap add android
```

Дальше каждая сборка:

```bash
npm run build          # dist/
npx cap sync android   # перенести dist/ и плагины в android-проект
```

Затем либо из терминала WebStorm:

```bash
cd android && ./gradlew assembleDebug
```

APK окажется в `android/app/build/outputs/apk/debug/`. Установка:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Либо `npx cap open android` и кнопка Run в Android Studio — удобнее, когда что-то сломалось
в Gradle и нужны его подробные сообщения.

## Отладка внутри APK

Capacitor — это обычный WebView, поэтому доступен полноценный DevTools:

1. Телефон подключён по USB, приложение открыто.
2. В Chrome на компьютере — `chrome://inspect`.
3. Найти устройство, нажать `inspect`.

Дальше консоль, сеть, элементы, брейкпоинты — всё как в вебе. Android Studio для отладки
фронтенда не нужна.

## Что коммитим

- Папку `android/` — **да**: там манифест, иконки, конфиг. Стандартная практика Capacitor,
  позволяет версионировать настройки платформы.
- `android/app/build/`, `*.apk`, `android/local.properties` — **нет**, они в `.gitignore`.
  `local.properties` содержит абсолютный путь к SDK, у каждой машины свой.

## Релизная сборка

Понадобится, только если захочется собрать подписанный APK «начисто». Требует создания
keystore. **Keystore и пароли в репозиторий не кладутся никогда.** Для личного
использования достаточно debug-сборки.
