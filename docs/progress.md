## План

Реализовывать строго по порядку, не перескакивая.

### Шаг 0 — каркас · ⬜ не начат

- Vite + React + TS + Tailwind v4, версии из [../CLAUDE.md](../CLAUDE.md#стек)
- Zustand store + persist в IndexedDB (`idb-keyval`)
- Типы из [data-model.md](data-model.md), `schemaVersion`, конвейер миграций
- Seed-данные из [progressions.md](progressions.md): 6 семейств, шаблоны A/B/Свободная
- **Экспорт и импорт JSON** — здесь, до появления данных, которые жалко потерять
- `npm run typecheck`, `oxlint`

### Шаг 1 — логирование тренировки · ⬜

- Выбор шаблона, старт тренировки
- Экран активной тренировки: предзаполнение прошлым результатом, степперы `−`/`+`,
  отметка подхода, автопереход к следующему упражнению
- `perSide`, `unit: 'seconds'`, `kind: 'binary'`
- Завершение тренировки, история, правка задним числом

На этом шаге приложением уже можно пользоваться. Проверять с телефона:
`npm run dev -- --host` и заход по локальному IP.

### Шаг 2 — Android и APK · ⬜

Рано и специально: сборка Android — единственное место с неприятными сюрпризами,
и ловить их надо на маленьком проекте. См. [android.md](android.md).

- Установка окружения, `npx cap add android`, первая сборка, APK на телефоне
- Проверить главное: доходит ли локальное уведомление при потушенном экране

### Шаг 3 — таймер отдыха · ⬜

- Плашка отсчёта, `+30 сек`, пропуск
- `@capacitor/local-notifications` — уведомление при свёрнутом приложении
- `@capacitor/haptics` — вибрация на отметке подхода и на конце отдыха

### Шаг 4 — храповик · ⬜

- Расчёт готовности к усложнению (правило в [data-model.md](data-model.md))

### Шаг 5 — прогресс · ⬜

### Шаг 6 — стрик и ачивки · ⬜

- Недельный стрик, цель тренировок в неделю

## Открытые вопросы

- Точные требования Capacitor 8 к JDK и Android SDK — уточнить на шаге 2 при первой сборке
  и записать в [android.md](android.md).
- Диапазоны и стартовые ступени в [progressions.md](progressions.md) — гипотеза. Проверяются
  первыми тренировками, правятся из вкладки «Настройки». Особенно ступень 5 брусьев:
  падение с 3×15 до 3×7–8 ожидаемо, но величину шага увидим на практике.
